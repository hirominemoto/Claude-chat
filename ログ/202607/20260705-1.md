`height: 9in` で高さを固定してるから、コンテンツがそれを超えると切れる。

**直す箇所**（`styles.css` の `@media print` 内の `.slide`）

```css
/* 変更前 */
.slide {
  border: 0;
  border-radius: 0;
  box-shadow: none;
  height: 9in;
  page-break-after: always;
  padding: 0.58in;
  width: 16in;
}

/* 変更後 */
.slide {
  border: 0;
  border-radius: 0;
  box-shadow: none;
  min-height: 9in;
  height: auto;
  page-break-after: always;
  padding: 0.58in;
  width: 16in;
  overflow: visible;
}
```

`height: 9in` → `min-height: 9in` + `height: auto` + `overflow: visible` に変えるだけ。
