問題は`html2canvas`がスライドのCSSを完全に再現できてないこと。スライドのサイズ指定を固定幅で取得するように修正すれば改善するはず。

`app.js`のPDFボタン部分だけ差し替えるよ。今のコードのPDF生成部分をこれに変えて：

```js
document.querySelector("#printButton").addEventListener("click", async () => {
  const btn = document.querySelector("#printButton");
  btn.textContent = "生成中...";
  btn.disabled = true;

  try {
    const { jsPDF } = window.jspdf;
    const slides = document.querySelectorAll(".slide");
    const pdf = new jsPDF({ orientation: "landscape", unit: "px", format: [1080, 607] });

    for (let i = 0; i < slides.length; i++) {
      const canvas = await html2canvas(slides[i], {
        scale: 1.5,
        useCORS: true,
        backgroundColor: "#ffffff",
        width: 1080,
        height: 607,
        windowWidth: 1080,
      });
      const imgData = canvas.toDataURL("image/jpeg", 0.95);
      if (i > 0) pdf.addPage();
      pdf.addImage(imgData, "JPEG", 0, 0, 1080, 607);
    }

    const name = report.storeShortName || "サロン診断";
    pdf.save(`${name}_診断レポート.pdf`);
  } catch (e) {
    alert("PDF生成に失敗しました。");
    console.error(e);
  } finally {
    btn.textContent = "PDF保存";
    btn.disabled = false;
  }
});
```
